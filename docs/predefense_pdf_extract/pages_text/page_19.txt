Gap Analysis
While machine learning and deep learning algorithms have been used to create systems for forecasting
CKD, building clinical outcome prediction models using EHRs and designing wearables health
monitoring systems, several important aspects that influence the contribution of this project to address
the world are lacking in the literature. All gaps were determined by a structured gap analysis as
demonstrated in Table 2.3 which details the gap in the existing body of work and the proposed work
and how it specifically addresses the gap.
